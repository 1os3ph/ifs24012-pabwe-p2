BOX MODEL

Eksperimen Box Model

Dari luar ke dalam: shadow luar → border tebal → padding → content. Ubah angka padding/border di CSS dan amati.

CONTENT Ini adalah area content.
  • content — teks / gambar di dalam element
  • padding — jarak di dalam border
  • border — garis tepi element
  • margin — jarak ke element tetangga
  • box-sizing: border-box — width termasuk padding + border

POSITION

Relative, Absolute, Fixed, Sticky

Badge oranye memakai absolute relatif ke parent relative. Header memakai sticky; tombol ↑ memakai fixed.

Parent (relative)
Absolute
  • static — default, mengikuti alur dokumen
  • relative — tetap di alur, jadi acuan absolute
  • absolute — keluar alur, posisi dari parent positioned
  • fixed — menempel ke viewport (back-to-top)
  • sticky — sticky sampai batas scroll (header)

EFEK & ANIMASI

Transition, Transform, Keyframes

Hover setiap kartu. Bandingkan transisi halus vs animasi terus berjalan (pulse).

Transition

Hover → naik perlahan (translateY + shadow).

transition: 0.25s ease

Transform Scale

Hover → membesar sedikit.

transform: scale(1.05)

Transform Rotate

Hover → miring 3 derajat.

transform: rotate(3deg)

Keyframes

Animasi pulse tanpa hover.

animation: pulse 2s infinite
