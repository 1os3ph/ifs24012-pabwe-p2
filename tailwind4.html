Tailwind v4

@theme — Design Tokens

Di Tailwind 4, konfigurasi warna/font bisa ditulis di CSS dengan @theme. Class seperti bg-brand muncul otomatis dari token --color-brand.

bg-brand

--color-brand

bg-brand-dark

--color-brand-dark

bg-brand-soft

--color-brand-soft

radius-card
rounded-card

--radius-card

Checklist latihan Tailwind 4

Layout

  • max-w-* + mx-auto (container)
  • flex / grid / gap
  • items-* / justify-*
  • col-span / order
  • responsive prefixes

Utilities

  • p-*, m-*, gap-*
  • text-*, font-*, tracking-*
  • bg-*, text-*, border-*
  • rounded-*, shadow-*
  • @theme tokens (v4)

Interaksi & Icons

  • hover: / focus: / active:
  • group / group-hover
  • peer / peer-checked
  • transition / transform
  • Tabler Icons (ti ti-*)
